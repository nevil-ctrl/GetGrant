## 📝 Заметки

- Чат лучше реализовать через Laravel Broadcasting + Pusher/Soketi для real-time
- Для статусов поступления использовать state machine (можно пакет Laravel State Machine)
- Фильтры в каталогах - использовать React для сложной логики
- Таймлайн - можно использовать библиотеку типа `react-vertical-timeline-component`
