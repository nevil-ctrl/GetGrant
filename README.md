📌 Описание проекта

GetGrant — онлайн‑платформа для подготовки студентов к поступлению за рубеж. Платформа обеспечивает полную воронку для лидов (учеников 9–11 классов и их родителей), предоставляет доступ к материалам после авторизации и позволяет изучать услуги компании, программы, страны, университеты, лицензии и аккредитации.

🛠 Технологический стек

Backend:

Laravel 12 (PHP 8.4)

Laravel Sanctum / Fortify — аутентификация SPA/API

Laravel Horizon — мониторинг очередей

PHPUnit — unit и feature тесты

Frontend:

Blade — шаблонизатор

Livewire — динамичные компоненты без JS

TailwindCSS — стили

Alpine.js (опционально) — лёгкая интерактивность

React (точечно) — чат, таймлайн, фильтры

База данных:

PostgreSQL с JSON-полями

Резервное копирование

Кеш / Realtime:

Redis — кеш, сессии, очереди, уведомления

Laravel Horizon

Хранение файлов:

S3 + Laravel Flysystem

Интеграции:

SMS (API оператора)

Email (Mailgun / Postmark / SMTP)

Zoom / Google Meet

DevOps / Развёртывание:

Docker + docker-compose

CI/CD — GitHub Actions

Laravel Telescope — мониторинг

Безопасность:

HTTPS / TLS

CSRF / XSS защита

Шифрование паролей (bcrypt / argon2)

RBAC — роли и права доступа
