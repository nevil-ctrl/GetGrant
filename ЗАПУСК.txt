## Вариант 1: Запуск через Docker Compose (Рекомендуется)

### Шаг 1: Подготовка
```powershell
cd C:\Users\nurzigit\Desktop\GetGrant
```

### Шаг 2: Запустить контейнеры
```powershell
docker compose up -d
```

### Шаг 3: Дождитесь готовности (1-2 минуты)
Контейнеры автоматически:
- Установят PHP зависимости (composer install)
- Установят JavaScript зависимости (npm install)
- Создадут базу данных
- Выполнят миграции
- Соберут фронтенд (npm run build)

### Шаг 4: Доступ к приложению
- 🌐 Веб-приложение: http://localhost:8000
- ⚡ Vite Dev Server: http://localhost:5173

## Вариант 2: Запуск через батник (Windows)

Просто двойной клик на `setup.bat` в папке проекта:
```
setup.bat
```

## Полезные команды

### Просмотр логов
```powershell
docker compose logs -f app      # Логи Laravel приложения
docker compose logs -f node     # Логи Node.js (Vite)
docker compose logs -f postgres # Логи базы данных
```

### Остановка всего
```powershell
docker compose down
```

### Перезагрузка контейнеров
```powershell
docker compose restart app
docker compose restart node
```

### Выполнение команд внутри контейнера
```powershell
# Laravel команды
docker exec getgrant_app php artisan migrate --fresh --seed
docker exec getgrant_app php artisan tinker

# Node/npm команды
docker exec getgrant_node npm run build
```

## Информация о БД и услугах

### PostgreSQL
- Хост: localhost:5433 (для подключения с хоста)
- Хост в Docker: postgres:5432
- БД: getgrant_db
- Пользователь: getgrant_user
- Пароль: secret

### Redis
- Хост: localhost:6379
- Используется для кеша и очередей

### Файловое хранилище
- Путь: storage/ (синхронизировано с контейнером)
- Публичная ссылка: storage/app/public → public/storage

## Решение проблем

### Контейнер приложения не запускается
```powershell
docker logs -f getgrant_app
# Проверить последние ошибки
```

### Port 8000 уже в использовании
```powershell
# Либо остановите процесс, использующий этот port
# Либо измените docker-compose.yml:8000 → 8001
```

### Ошибка "Composer could not find vendor"
```powershell
docker exec getgrant_app composer install
```

### Миграции не выполнены
```powershell
docker exec getgrant_app php artisan migrate --force
docker exec getgrant_app php artisan db:seed
```

### Vite не компилирует ассеты
```powershell
docker exec getgrant_node npm install
docker exec getgrant_node npm run build
```

## Структура проекта

```
GetGrant/
├── app/                    # Исходный код приложения
├── resources/             # Views и фронтенд ресурсы
```
