## 🐛 Решение Проблем

### ❌ Контейнер приложения не запускается

**Проверить логи:**
```powershell
docker logs -f getgrant_app
```

**Возможные причины:**
- Порт 8000 занят → измените в docker-compose.yml
- Нет доступа к БД → проверьте PostgreSQL контейнер
- Ошибка в коде → проверьте логи выше

### ❌ Ошибка "Port 8000 already in use"

**Решение 1:** Найти и убить процесс
```powershell
Get-Process -Name "php" | Stop-Process -Force
Get-Process -Name "node" | Stop-Process -Force
```

**Решение 2:** Изменить порт в docker-compose.yml
```yaml
ports:
  - "8001:8000"  # Вместо 8000:8000
```

### ❌ Ошибка миграций БД

```powershell
# Пересоздать БД
docker exec getgrant_app php artisan migrate:fresh --seed

# Или проверить подключение
docker exec getgrant_app php artisan tinker
>>> DB::connection()->getPdo();
```

### ❌ npm не находит модули

```powershell
# Переустановить
docker exec -it getgrant_node bash
cd /var/www/html
rm -rf node_modules package-lock.json
npm install
npm run build
```

### ❌ Файлы storage не доступны

```powershell
# Пересоздать ссылку
docker exec getgrant_app php artisan storage:link

# Проверить права
docker exec getgrant_app ls -la storage/
```
